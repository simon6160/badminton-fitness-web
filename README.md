# 羽球員體適能訓練管理網站（免登入・GitHub Pages 即開即用）

專為羽球隊與體適能教練設計的響應式網頁系統，**免帳號密碼登入**（球員輸入名字即可進入打卡），完整涵蓋 **8 大羽球專項訓練分類、33 項訓練動作、4 週漸進週期**，並支援一鍵部署至 **GitHub Pages** 與免費 **Google 試算表全隊雲端同步**。

---

## 功能特色

- **免帳號登入入口**：球員打開網址直接輸入名字（或點選現有名字）即可進入今日課表；新球員輸入名字會自動建立個人檔案。
- **多週自動排程與 4 週漸進循環**：系統以每週一為單位，**跨入新的一週自動產生正確日期與完整課表**，並自動推進 `W1 適應期 → W2 基礎期 → W3 強化期 → W4 減量檢測期` 循環；每週打卡與疼痛紀錄獨立歸檔、互不覆蓋。
- **球員訓練端（手機／電腦皆適用）**：勾選每日指定訓練項目、填寫實際完成次數與時間、身體疲勞程度（1–10）、疼痛不適部位通報與訓練心得。
- **教練管理端**：支援「◀ 上一週／下一週 ▶」切換、「⚡ 一鍵預排未來 4 週」、「📋 複製本週課表到下週」、每日項目的**新增、修改、刪除（CRUD）**與全隊完成率／疼痛預警監控。
- **訓練統計分析**：全隊每週完成率長條圖、個人體能進步趨勢折線圖（支援登錄立定跳遠、原地垂直跳、六點移動步伐、棒式支撐）、個人訓練歷史篩選查詢，以及 **Excel 相容 CSV／JSON 匯出**。
- **雙模式儲存**：預設零設定即可使用瀏覽器本機儲存；填入免費 Google Apps Script 網址即立刻升級「全隊跨手機即時雲端同步」。

## 步驟一：3 分鐘放上 GitHub 並免費上線（GitHub Pages）

本專案採用純靜態網頁設計（零建置、免安裝 Node.js），上傳即上線：

1. 登入 [GitHub](https://github.com)，點擊右上角 **`+` → `New repository`** 建立新倉庫（例如命名為 `badminton-fitness-web`，權限設為 **Public**）。
2. 將本資料夾內的所有檔案（`index.html`、`styles.css`、`config.js`、`data.js`、`app.js`、`README.md`、`google-apps-script/`）上傳到該倉庫（可直接用網頁 **Upload files** 拖曳上傳，或使用 `git push`）。
3. 進入倉庫上方的 **`Settings`** → 左側選單 **`Pages`**。
4. 在 **Build and deployment** 區塊：
   - **Source**：選擇 `Deploy from a branch`
   - **Branch**：選擇 `main` 與 `/ (root)`，點擊 **`Save`**。
5. 等待約 1 分鐘重新整理，頁面頂端會出現您的正式網址（例如 `https://您的帳號.github.io/badminton-fitness-web/`），手機與電腦都能直接開啟！

## 步驟二（選用）：5 分鐘免費串接 Google 試算表，讓全隊手機同步

若希望**教練在電腦排課，球員各自用手機輸入名字打卡，教練電腦即時看到全隊完成率**：

1. 建立一張全新的 [Google 試算表](https://sheets.google.com)（例如命名「羽球隊體適能紀錄」）。
2. 點擊上方選單 **`擴充功能` → `Apps Script`**。
3. 將本專案內 `google-apps-script/Code.gs` 的程式碼**全部複製貼上**取代原內容，按 `Ctrl + S` 儲存。
4. 點擊右上角 **`部署` → `新增部署作業`**：
   - 左側齒輪選擇 **`網頁應用程式`**
   - **執行身分**：`我`
   - **誰可以存取**：`所有人`
   - 點擊 **`部署`** 並完成 Google 權限授權，複製產生的 **網頁應用程式網址**（結尾為 `/exec`）。
5. 打開本專案的 `config.js`，將該網址貼入 `CLOUD_API_URL` 並更新回 GitHub：
   ```js
   window.TEAM_CONFIG = {
     TEAM_NAME: '羽球專項體適能訓練中心',
     CLOUD_API_URL: 'https://script.google.com/macros/s/您的部署ID/exec',
     COACH_PASSCODE: '' // 若不想讓球員誤改課表，可設定簡易密碼如 '8888'
   };
   ```
6. 完成！之後全隊只要打開同一個 GitHub Pages 網址，就能即時同步資料，而且教練還可以直接打開 Google 試算表檢視自動整理的 **每週課表、球員完成率總表、球員打卡明細、身體狀況與疼痛回報** 四張工作表！

## 專案檔案結構

```text
badminton-fitness-web/
├── index.html                   # 主網站介面（免登入名字入口＋四大功能分頁）
├── styles.css                   # 響應式樣式表（零外部 CDN 相依、支援深淺主題）
├── config.js                    # 球隊名稱、雲端同步網址與教練密碼設定
├── data.js                      # 8 大分類、33 項羽球專項預設課表與週期規則
├── app.js                       # 完整互動邏輯、CRUD、Canvas 圖表與雲端同步
├── google-apps-script/
│   └── Code.gs                  # 免費 Google 試算表後端 API 腳本
└── README.md                    # GitHub Pages 上線與雲端串接教學
```
